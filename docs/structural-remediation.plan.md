- Risk: bounds "alignment" silently widens/narrows the HTTP/MCP contract → mitigation: winners table + cross-layer test vectors include explicit reject cases; any behavior change needs product sign-off; rollback: revert the step commit.
- Risk: extraction drops a `setTimeout`/abort/intent/activity line → mitigation: per-extraction gates + reviewer line-diff of those concerns; rollback: revert that extraction commit only.
- Risk: spawn unification erases a grace/cap distinction (5s vs 1s kill, fail vs keep-newest) → mitigation: difference table first, explicit params, one-site-per-commit; rollback: revert that site's commit.
- Risk: file move breaks a runtime-relative URL → mitigation: flat layout, per-move fix list + clean-build smoke; rollback: revert the move commit.
- Global rollback: `git revert` of the small phase commits in reverse order; no state repair (schema, state dir, and registrations untouched; bak deletion restorable from git if ever needed).
